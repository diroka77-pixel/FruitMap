# FrutaMapa · primera versión Android

Abre el proyecto en Android Studio o súbelo a GitHub. El workflow genera una APK de prueba descargable en Artifacts. Datos guardados en este dispositivo mediante almacenamiento local del WebView; la sincronización entre teléfonos aún no está implementada.

La pantalla permite buscar frutas, seleccionar meses y provincias, consultar mercados y añadir o modificar fichas, campañas y empresas. Se incluyen fuentes oficiales enlazadas. Los datos iniciales son deliberadamente limitados: la cobertura nacional de operadores y los volúmenes individuales requieren comprobación mercado a mercado. No se presentan como directorio exhaustivo.

La imagen de cada fruta se puede establecer con una URL pública en su ficha. Para una versión de producción hacen falta imágenes autorizadas, límites geográficos oficiales de comarcas, revisión de licencias y una base de datos compartida con cuentas de edición.
